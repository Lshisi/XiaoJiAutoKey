# 本地输入查看

仓库内的 [scripts/input-viewer.html](../scripts/input-viewer.html) 是开发时手动观察键盘、鼠标和滚轮输出的离线页面。双击后用 Edge、Chrome 等桌面浏览器打开即可，无需编译、启动服务或安装依赖。页面不参与软件构建和发布打包。

## 使用

1. 如需观察小叽输出，在“全局设置 → 生效范围”临时关闭“仅游戏客户端前台时生效”。先只启用要观察的项，连发间隔可先设为 100–200ms。
2. 启动小叽，回到页面，点击“开始接收”。键盘输入需要焦点停留在接收区；鼠标点击和滚轮需要指针位于接收区内。
3. 用逐键统计查看各键的按下、松开、重复、按住时长和连发间隔，用事件日志核对实际顺序和修饰键标志。
4. 用设备、动作和名称筛选日志。“冻结日志显示”只冻结列表，后台接收和累计统计继续；操作筛选控件会使焦点离开接收区，继续观察时点“返回接收区”。
5. 需要分享现场记录时，点击“导出 JSON”。文件包含累计统计、最近 2,000 条记录、浏览器信息与 DPI 比例，不受当前筛选影响。刷新或关闭页面会清除内存记录。
6. 结束后恢复小叽的游戏前台限制。

清空记录会重新开始统计并聚焦接收区，不会发送任何键盘或鼠标事件。操作接收区以外的页面按钮不会计入鼠标测试。

## 可以观察什么

| 输入 | 观察内容 |
| --- | --- |
| 普通键、功能键、左右修饰键、小键盘 | `keydown` / `keyup`、`code`、`key`、`location`、`repeat` |
| 多修饰键组合 | 每个事件的 Ctrl / Alt / Shift / Meta 标志和组合名称；AltGr 状态也会显示 |
| 长按 | 当前仍按住的键、本次持续时间、上次完整按住时长、系统自动重复事件 |
| 鼠标左键、右键、中键、两个侧键 | `mousedown` / `mouseup`、`click` / `auxclick` / `dblclick`、`button`、`buttons`、坐标 |
| 垂直和水平滚轮 | 方向、`deltaX` / `deltaY` / `deltaZ`、`deltaMode`、事件次数与同方向事件间隔 |
| 鼠标移动 | 实时接收区坐标和屏幕坐标，可选每 50ms 采样写入日志 |
| 高频触发反馈 | 状态与次数跟随浏览器画面刷新；最近触发的键位及鼠标按钮保留 120ms 余光 |
| 观察中断 | 失焦、页面隐藏、暂停和恢复记录；中断后按住状态标为未知 |

键盘按 `code` 区分，例如 `Digit1` 和 `Numpad1`、`ControlLeft` 和 `ControlRight`。鼠标日志使用 `Mouse1` 左键、`Mouse2` 右键、`Mouse3` 中键、`Mouse4` / `Mouse5` 侧键；浏览器的 `button` 值分别是 0 / 2 / 1 / 3 / 4。

## 常见场景的判断

| 场景 | 页面中的预期现象 |
| --- | --- |
| 单键开关连发 | 主键的 down / up 持续交替，次数大致成对增加 |
| `Ctrl+Alt+1` 连发 | `Digit1` 的 down / up 持续交替，每个主键事件的 Ctrl、Alt 均为 `true` |
| 单键或整个组合长按 | 按下后保持，可能有 `repeat=true` 的重复 keydown；释放前不应出现该键的 keyup |
| 鼠标键连发 | 同一鼠标键的 down / up 交替；浏览器还可能生成 click / auxclick / dblclick |
| 滚轮步骤 | 对应方向的 wheel 事件增加，查看原始 delta 及单位核对方向 |
| 检查停止后是否粘修饰键 | 停止小叽后重新聚焦页面，手动按一次 A，用这个新事件的修饰键标志判断 |
| 检查鼠标是否仍按住 | 停止小叽后把指针移入接收区，用新鼠标事件的 `buttons` 核对 |

## 统计口径与边界

- 实时状态使用 `requestAnimationFrame` 合并同一画面内的更新。键盘、鼠标按下及滚轮触发有独立的 120ms 余光；快速连发时显示持续活跃并累计次数，不排队播放动画。余光不改变实际按住状态、原始事件时间或按住时长。
- 逐键统计和日志最多每 125ms 批量刷新，复用已有行，仅更新变化的内容。单次按下、松开可能发生在同一画面内，判断次数和先后顺序时查看统计与日志；不能要求每个短按都在屏幕上单独闪烁。
- 时间为页面收到事件时的 `performance.now()`，日志相对时间从打开或清空记录时计算。原始事件 `timeStamp` 也保留在详情中。它反映浏览器观察到的时间，不是驱动调用的精确计时。
- 键盘“按下”包含所有 keydown，`repeat=true` 的事件另在 repeat 列累计。鼠标 click、auxclick 和 dblclick 不会额外增加 down / up 次数。
- 间隔计算相邻按下的时间差，包含键盘 repeat；滚轮使用同方向相邻事件。平均、最小和最大间隔只使用观察连续的样本，悬停间隔单元格可看最小值、最大值和样本数。
- 失焦、暂停或页面隐藏不会补造 keyup / mouseup；按住状态变为未知并中断间隔计算。恢复后用新事件确认状态。修饰键或鼠标按住标志推断出的状态会标注“标志”，不增加松开次数。
- 鼠标移动仅在启用时每 50ms 采样写入日志；坐标使用浏览器的 CSS 像素，屏幕坐标不保证等同于驱动使用的物理像素。滚轮事件也可能被浏览器合并，不能直接把事件数或 delta 当成固定格数。
- 列表最多显示筛选后的最近 160 条，环形缓冲保留最近 2,000 条（包含接收状态记录）；超过上限覆盖旧日志，累计统计仍保留。导出记录按时间从旧到新排列，并注明覆盖条数。
- 本页无法区分物理输入和驱动输出，无法捕获其他窗口的输入，也无法拦截所有系统快捷键。`Ctrl+1`、`Alt+Tab`、Windows 键、媒体键和鼠标侧键等可能由浏览器或系统先处理。网页收到输入不代表游戏已绑定或响应对应动作。
