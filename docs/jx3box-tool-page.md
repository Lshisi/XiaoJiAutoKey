# 小叽按键 - 使用说明

## 1. 开关模式（Toggle）—— 一键启停连发

1. 打开软件，点击「添加按键」，录入需要连发的按键
2. 选择模式为「开关」，设置按键间隔（毫秒）
3. 勾选启用该按键
4. 设置全局启停快捷键（点击启停快捷键输入框录制）
5. 按下启停快捷键，所有勾选的开关模式按键同时开始连发
6. 再按一次启停快捷键，全部停止

例：启停键设置为"~"，添加"1"、"2"、"3"三个按键（开关模式），按~后三个键同时按照各自设定的间隔连发，再按~全部停止。

ps. 每个按键有独立的间隔设置，互不影响。适合挂机、日常技能循环等需要多键同时连发的场景。

## 2. 按压模式（Hold）—— 按住才连发

1. 添加按键时选择模式为「按压」
2. 设置按键间隔，勾选启用
3. 按下启停快捷键启动工具
4. 按住该按键时连发，松开立即停止

例：添加"F"为按压模式，启动工具后，按住F连发F，松开F停止。不按就不发。

ps. 按压模式适合需要精确控制的场景，比如某个技能只在特定时机需要连打。

## 3. 按压优先级 —— Hold 压制 Toggle

当你按住任意按压模式的按键时，所有开关模式的连发会自动暂停。松开后开关模式恢复连发。

例：开关模式的"1"、"2"正在连发，此时按住按压模式的"F"，"1"、"2"暂停，只有"F"在连发。松开"F"后，"1"、"2"恢复。

ps. 这个机制让你可以在自动连发的同时，随时按住某个键临时接管控制权。

## 4. 支持的按键类型

- 键盘：所有常规按键
- 鼠标：左键、右键、中键、侧键

## 5. 其他功能

- 启停提示音：可在界面开启/关闭，启动和停止时播放不同提示音
- 配置自动保存：所有设置自动保存到本地 config.json，下次打开自动加载
- 支持自定义配置文件路径，方便多套配置切换

## 6. 注意事项

- 首次使用需安装 DD 驱动并重启电脑
- 延迟间隔建议 80~200ms，过快可能触发检测
- 部分杀毒软件可能误报，请添加信任
- 本工具仅供学习交流，使用后果自负
