# 小叽按键 - 轻松上手版

一句话：让手指下班，但别让脑子也下线。😎

小叽按键是一个 Windows 按键连发工具，支持键盘、鼠标、按键连发、宏循环、提示音、悬浮窗和 DD/HID 驱动。适合需要稳定重复按键的场景。

## 先来个 30 秒上手

1. 解压压缩包。
2. 右键 `XiaoJiAutoKey.exe`，用管理员身份运行。
3. 进「按键连发」页，点「添加按键」。
4. 录入你想连发的键，比如 `1`、`2`、`F`。
5. 设置一个「启停快捷键」。
6. 按快捷键启动，再按一次停止。

好了，现在你的手指可以喝口水了。☕

## 两种连发玩法

| 玩法 | 适合谁 | 怎么理解 |
| --- | --- | --- |
| 开关模式 | 想按一下就自动跑的人 | 按启动后一直连发，再按停止 |
| 按压模式 | 想自己掌控节奏的人 | 按住才连发，松开就停 |

### 开关模式

适合固定循环，比如 `1`、`2`、`3` 一直按。

例子：把 `1`、`2`、`3` 都设成开关模式，再设一个启停键。按下启停键后，它们就会按你设置的间隔自动连发。

默认间隔是 `30ms`，最低 `10ms`。别一上来就拉满，机器和游戏都需要一点尊重。🙂

### 多段宏小技巧

这个不是「宏循环」功能，是按键连发的一个用法：小叽只负责连发 `F12`，游戏里负责把不同宏绑到 `F12` 的组合键上。

![多段宏组合键示例](images/multi-macro-hotkeys.png)

我个人比较喜欢这样放：

- 主循环：`F12`
- 第二段：`Shift + F12`
- 第三段：`Ctrl + F12`
- 第四段：`Alt + F12`

小叽这边只需要在「按键连发」里添加一个 `F12`，设成开关模式或按压模式都行，看你习惯。

想换段的时候，不用切小叽配置，直接按住修饰键：

- 不按修饰键：游戏吃到 `F12`。
- 按住 `Shift`：游戏吃到 `Shift + F12`。
- 按住 `Ctrl`：游戏吃到 `Ctrl + F12`。
- 按住 `Alt`：游戏吃到 `Alt + F12`。

简单说：小叽负责一直敲门，`Shift/Ctrl/Alt` 负责告诉游戏“这次走哪扇门”。切段很快，手不用到处乱飞。😄

### 按压模式

适合临时爆发，比如你只想按住 `F` 的时候连发。

例子：把 `F` 设成按压模式。启动工具后，按住 `F` 就连发，松开就停。

## 连发优先

这个功能的意思是：我现在按住某个按压键，你们这些开关连发先安静一下。

适合临时接管节奏的情况。

- 关闭：开关模式和按压模式各玩各的。
- 开启：按住参与连发优先的按压键时，开关模式会暂停，松开后恢复。

例子：`1`、`2` 正在自动连发，你按住 `F`。如果 `F` 参与连发优先，那么 `1`、`2` 会先暂停，只让 `F` 工作。

## WASD 防卡位

在「按键连发」页右侧可以打开「WASD 防卡位」。

开启后，按住 `W/A/S/D` 移动时，开关连发会临时降速；松开移动键后恢复。

适合一边移动一边连发时，感觉走位被高频按键拖住的情况。简单说：别让连发把你焊在地上。🚶

## 暂停键

暂停键就是临时刹车。

在「按键连发」页添加一个暂停键，比如 `Ctrl`。启动连发后，按住 `Ctrl` 时开关模式会暂停，松开后恢复。

适合需要临时停手、躲技能、切目标、看一眼队友是不是又倒了的时候。

## 宏循环

宏循环适合按顺序执行一串按键。

用法很简单：

1. 左侧进「宏循环」。
2. 新建宏，或者用默认宏。
3. 点「添加步骤」，录入按键顺序。
4. 设置每一步间隔。
5. 设置触发键。
6. 选择循环次数，`0` 表示无限循环。
7. 按触发键开跑。

例子：录入 `1 -> 2 -> 3`，每步 `30ms`，循环次数设 `0`。按下触发键后，它就会循环按 `1、2、3`。

宏也可以设置暂停键。注意：宏暂停键只管宏，不管按键连发页的暂停键。各管各的，互不抢饭碗。

## 悬浮窗

悬浮窗可以显示当前连发和宏循环状态。

你可以：

- 在按键连发页或宏循环页分别打开悬浮窗显示。
- 拖动悬浮窗位置。
- 锁定位置，防止手滑。
- 调整透明度。
- 双击未锁定的悬浮窗，快速回到对应设置页。

双击规则也很人性：

- 只显示按键连发：进按键连发页。
- 按键连发和宏循环都显示：优先进按键连发页。
- 只显示宏循环：进宏循环页。

## 驱动管理

左侧「驱动管理」页可以查看 DD/HID 状态。

你可以在这里：

- 看当前使用的是 DD 还是 HID。
- 切换驱动模式。
- 安装或卸载 HID。
- 查看驱动文件和设备状态。

发布包已经带了这些运行库：

- `driver/DD32.dll`
- `driver/DD64.dll`
- `driver/hid/ddhid.63340.dll`

如果切换或卸载 HID 时提示重启，就重启。Windows 有时候比较慢热，不重启它会装作没听见。

## 门派主题

在「全局设置」里可以切换剑三门派主题。

界面颜色会跟着门派变，默认是藏剑。深色模式也会跟随系统自动适配，晚上看不至于亮得像开了闪光弹。🌙

## 提示音

按键连发和宏循环可以分别设置开启/关闭提示音。

支持：

- `mp3`
- `wav`
- `wma`
- `mid`

不想听也可以关。安静，是一种美德。

## 多配置方案

你可以建多个配置方案，比如：

- 日常
- 副本
- 战场
- 今天想当无情按键机器

每个方案都有自己的按键列表、宏、快捷键和暂停键。切换方案后会自动保存，下次打开还在。

## 常见小提醒

- 运行时会锁定编辑按钮，避免你一边连发一边误改配置。
- 打开录制或编辑弹窗时，会临时屏蔽快捷键，防止误触。
- 快捷键可以清空后重新录。
- 关闭窗口时可以选择最小化到托盘。
- 部分杀毒软件可能误报，按需添加信任。
- 本工具仅供学习交流，请合理使用。
