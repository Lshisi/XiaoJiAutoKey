# 小叽按键 - 使用说明

## 1. 开关模式（Toggle）—— 一键启停连发

1. 打开软件，点击「添加按键」，录入需要连发的按键
2. 选择模式为「开关」，设置按键间隔（毫秒）
3. 勾选启用该按键
4. 设置全局启停快捷键（点击启停快捷键输入框录制）
5. 按下启停快捷键，所有勾选的开关模式按键同时开始连发
6. 再按一次启停快捷键，全部停止

例：启停键设置为"~"，添加"1"、"2"、"3"三个按键（开关模式），按~后三个键同时按照各自设定的间隔连发，再按~全部停止。

ps. 每个按键有独立的间隔设置，默认 30ms，最低 1ms，互不影响。间隔表示相邻两次按下事件之间的时间。适合挂机、日常技能循环等需要多键同时连发的场景。

### 多段宏组合键用法（可选）

多段宏不是「宏循环」功能，而是按键连发的一种使用方式：小叽按键只负责连发一个基础按键，例如 `F12`；游戏内将不同宏绑定到 `F12` 及其组合键上，通过按住修饰键切换不同段位。

推荐绑定方式：

- 主循环：`F12`
- 第二段：`Shift + F12`
- 第三段：`Ctrl + F12`
- 第四段：`Alt + F12`

小叽按键中只需要在「按键连发」页面添加一个 `F12`，按使用习惯设置为开关模式或按压模式。需要切换到其他段时，不用切换小叽配置，直接按住对应修饰键：

- 不按修饰键：游戏接收 `F12`
- 按住 `Shift`：游戏接收 `Shift + F12`
- 按住 `Ctrl`：游戏接收 `Ctrl + F12`
- 按住 `Alt`：游戏接收 `Alt + F12`

这种方式适合在游戏内维护多段宏，小叽按键负责稳定连发同一个基础键，具体执行哪一段由游戏内组合键绑定决定。

## 2. 按压模式（Hold）—— 按住才连发

1. 添加按键时选择模式为「按压」
2. 设置按键间隔，勾选启用
3. 按下启停快捷键启动工具
4. 按住该按键时连发，松开立即停止

例：添加"F"为按压模式，启动工具后，按住F连发F，松开F停止。不按就不发。

ps. 按压模式适合需要精确控制的场景，比如某个技能只在特定时机需要连打。

## 3. 连发优先模式（可选）

连发优先是一个可开关的选项，位于按键连发页面右侧面板，默认关闭。按压模式按键还可以单独设置是否参与连发优先。

关闭时（默认）：按压模式和开关模式完全独立，互不影响。按住按压键连发的同时，开关模式的连发照常进行。

开启时：当你按住参与连发优先的按压模式按键时，所有开关模式的连发会自动暂停。松开后开关模式恢复连发。

例（关闭连发优先）：设置Q为按压模式，F12为开关模式。启动工具后F12一直连发，按住Q时Q也连发，F12不受影响继续连发。

例（开启连发优先）：开关模式的"1"、"2"正在连发，此时按住已参与连发优先的按压模式"F"，"1"、"2"暂停，只有"F"在连发。松开"F"后，"1"、"2"恢复。

ps. 连发优先适合需要临时接管控制权的场景。关闭则适合需要多种按键同时独立连发的场景。

## 4. 暂停按键 —— 按住暂停所有连发

1. 在「按键连发」页面的按键列表下方，可以看到「暂停键」区域
2. 点击「+」按钮添加暂停按键
3. 录制一个按键作为暂停键
4. 启动连发后，按住暂停键时所有开关模式连发暂停，松开后恢复

例：添加"Ctrl"为暂停键，开关模式的"1"、"2"正在连发，按住Ctrl时"1"、"2"暂停，松开Ctrl后恢复连发。

ps. 暂停键可以设置多个，按住任意一个暂停键都会暂停所有开关模式连发。暂停键与连发优先模式独立，无论连发优先是否开启，暂停键都生效。

### WASD 防卡位

在「按键连发」页面右侧的连发优先区域，可以开启「WASD 防卡位」。

开启后，按住 W/A/S/D 移动时，开关模式连发会临时降速，松开移动键后恢复原来的连发频率。这个功能适合移动时容易被高频连发影响走位的场景。

## 5. 宏设置 —— 按键序列自动执行

1. 在左侧导航切换到「宏循环」页面
2. 创建一个新宏（或使用默认宏）
3. 点击「添加步骤」，逐个录入按键和每步之间的间隔时间
4. 设置触发模式：
   - 开关模式：按一次快捷键开始循环执行，再按一次停止
   - 按压模式：按住快捷键时执行，松开停止
5. 设置循环次数（0 = 无限循环）
6. 录制宏的触发快捷键
7. 如需临时停手，可以添加宏暂停键
8. 按下触发键即可执行宏序列

例：录制"1→2→3"三个按键，间隔各30ms，设为开关模式无限循环。按下触发键后自动循环按1、2、3。

ps. 宏步骤间隔默认 30ms，最低 1ms，表示当前步骤按下到下一步骤按下的时间。宏暂停键只暂停当前宏执行，不影响按键连发页面的暂停键。宏触发键、宏步骤按键和宏暂停键会做冲突校验，避免误触。按键连发和宏循环是两种独立模式，通过左侧导航切换，运行时不可切换模式。

## 6. 门派主题

在「全局设置」页面可以选择剑三门派主题，界面配色会随门派变化。未配置时默认展示藏剑主题，不再提供无主题选项。支持的门派包括：少林、万花、七秀、纯阳、天策、藏剑、五毒、唐门、明教等。门派选择使用图标菜单，门派图标改用 SVG 渲染，深色模式下显示更清晰。

## 7. 深色模式与多屏缩放

- 软件会跟随 Windows 系统明暗主题切换，窗口、卡片、表格、滚动条和门派主题色会自动适配
- 支持高 DPI 和多显示器缩放环境，拖到不同缩放比例的屏幕时会刷新布局，避免窗口过小或内容挤压
- 主窗口使用圆角无边框标题栏，常用弹窗保持统一圆角样式，并支持右上角关闭

## 8. 驱动管理

- 左侧「驱动管理」页可以查看当前使用的 DD/HID 运行模式和驱动状态
- 可以在 DD 和 HID 之间切换；切换到 HID 时会按提示安装驱动并重启程序
- 支持卸载 HID 驱动；如果 Windows 仍有设备或服务等待释放，软件会提示手动重启，避免强制重启带来的风险
- 发布包内置 `driver/DD32.dll`、`driver/DD64.dll` 和 `driver/hid/ddhid.63340.dll`

## 9. 多配置方案

- 支持创建多个配置方案（如"藏剑"、"花间"等），在按键连发或宏循环页面顶部下拉框切换
- 支持重命名和删除配置方案
- 配置自动保存，下次打开自动加载上次使用的配置方案
- 每个配置方案包含独立的按键列表、宏配置、启停快捷键和暂停键设置

## 10. 支持的按键类型

- 键盘：所有常规按键
- 鼠标：左键、右键、中键、侧键

## 11. 自定义提示音

- 在「按键连发」或「宏循环」页的提示音旁点击音效图标，可以分别设置开启和关闭的提示音
- 按键连发和宏循环可以分别设置提示音文件、提示音开关和音量
- 支持 mp3、wav、wma、mid 格式
- 在弹窗中点击输入框选择自定义音频文件，可以试听音效、调整音量，也可以恢复默认内置音效

## 12. 状态悬浮窗

- 可在按键连发页和宏循环页分别开启悬浮窗显示
- 悬浮窗可显示连发状态、宏状态、当前快捷键和宏循环信息
- 支持拖动位置、锁定位置和调节背景透明度
- 未锁定时双击悬浮窗主体区域，可以快速打开对应配置界面；只显示循环连发时进入宏循环页，同时显示按键连发和循环连发时优先进入按键连发页
- 多显示器环境下会跟随保存的位置显示，不会固定在主屏
- 支持高 DPI / 多屏缩放刷新，跨屏或缩放变化后会同步更新尺寸和锁按钮位置

## 13. 其他功能

- 启停提示音：可在设置中开启/关闭，启动和停止时播放不同提示音
- 运行时锁定：工具启动后，添加按键、快捷键录制、配置切换、模式切换等编辑操作自动禁用，防止误操作
- 弹窗屏蔽：打开编辑弹窗时自动屏蔽启停快捷键和宏触发，防止误触
- 快捷键清空：按键连发启停键和宏触发键都可以一键清空后重新设置
- 系统托盘：关闭窗口可选择最小化到托盘，双击托盘图标恢复
