# 提示音配置

按键页和循环页保留「开启提示音」整组开关。点击旁边的音乐图标，弹窗左侧直接列出当前页的提示事件，点击后在右侧设置该项开关、音量、自定义音频、试听和恢复默认音频，不再使用类别或事件下拉框。关闭的事件会在列表中标注「关闭」。

从按键页打开时，只显示按键连发的 8 项事件；从循环页打开时，只显示循环连发的 4 项事件和录制的 2 项事件。两页分别保存本页范围内的设置，不覆盖另一页的提示音配置。窗口较窄时，事件列表和设置区改为上下排列。

播放必须同时满足整组开关和单项开关开启，且音量大于 0。录制提示受循环页整组开关控制。试听由用户点击触发，不受整组或单项开关影响。

## 默认音频文件

源文件放在项目的 `assets/audio/` 下，构建与打包后位于 exe 同级的 `audio/`。内置文件统一使用 WAV，自定义文件支持 mp3、wav、wma、mid、midi。

| 文件名 | 事件 ID | 触发时机 | 默认音量 |
| --- | --- | --- | --- |
| `按键开启.wav` | `repeatOn` | 按键连发工具启动 | 80 |
| `按键关闭.wav` | `repeatOff` | 按键连发工具停止 | 80 |
| `独立开启.wav` | `independentOn` | 未选择独立键时，首次选中一个独立键 | 65 |
| `独立关闭.wav` | `independentOff` | 再次按当前独立键，停止该键连发 | 65 |
| `按键切换.wav` | `independentSwitch` | 从一个独立键切换到另一个独立键 | 60 |
| `按键切换.wav` | `sequenceSwitch` | 切换模式下，按列表下方的「切换键」更换正在连点的按键 | 60 |
| `按键暂停.wav` | `repeatPause` | 按住暂停键，首次进入按键暂停 | 60 |
| `按键恢复.wav` | `repeatResume` | 松开最后一个暂停键，解除按键暂停 | 60 |
| `循环开启.wav` | `macroOn` | 循环连发成功启动 | 80 |
| `循环关闭.wav` | `macroOff` | 循环连发停止，沿用原有关闭提示 | 80 |
| `循环暂停.wav` | `macroPause` | 循环运行中按住暂停键 | 60 |
| `循环恢复.wav` | `macroResume` | 松开最后一个循环暂停键 | 60 |
| `录制开始.wav` | `recordingOn` | 倒计时结束，正式开始录制 | 80 |
| `录制结束.wav` | `recordingOff` | 按 F10／停止按钮、达到容量，或取消正在进行的录制 | 80 |

共 14 项事件、13 个默认音频文件。「独立换键」是在独立模式中直接按另一个键，例如从连点 1 改为连点 2；「切换模式换键」是按列表下方的「切换键」，按顺序更换正在连点的按键。两项默认共用 `按键切换.wav`，但各自的开关、音量和自定义路径独立保存，可以换成不同的声音。

13 个默认 WAV 均已放入 `assets/audio/`，统一为 24 kHz、16 位 PCM、单声道格式，构建和打包时会复制到 exe 同级的 `audio/`。新增默认音频也可直接放入已构建程序的 `audio/` 目录，无需改代码或重新构建。默认文件缺失时，设置中显示「待放入默认音频」，实际触发时保持静音。

设置自定义路径后直接使用该文件；文件不存在时显示缺失，需重新选择或恢复默认音频。

## 触发规则

- 声音跟随引擎实际选择状态的变化；键盘重复按下和程序自己发送的连发不会重复提示。
- 独立键切换只播放一次换键提示，不叠加独立关闭和独立开启。
- 独立模式开启「防误停」后，再按当前键不改变状态，不播放启停音。
- 切换模式只有一个可用段、或切换后仍是当前段时，不播放换段音。停用的段沿用引擎已有规则跳过。
- 暂停只反馈暂停键的生效／解除；多个暂停键按住时，仅首次暂停和最后一次解除提示。按压优先接管和前台窗口限制不会触发这两项提示。
- 整体停止只播放整体关闭提示，不叠加独立关闭、暂停恢复。有限次数循环结束继续使用现有循环关闭提示，不增加单独的完成事件。
- 取消倒计时尚未开始的录制不会播放录制结束音。
- 按键、循环、录制、试听分别使用播放通道。同一通道优先播放最新状态，停止旧提示并替换尚未播放的旧请求；取消固定的 150ms 全局丢弃逻辑。
- 文件查找、音频设备预热和播放在后台工作线程中完成；实际提示优先于尚未处理的预热。退出、关闭试听和重启更新时清理对应设备；更新覆盖文件前释放全部音频句柄。

## 配置存储

配置仍保存在 exe 同级的用户 `config.json` 中，发布包不包含该文件。

```json
{
  "beepEnabled": true,
  "macroBeepEnabled": true,
  "sounds": {
    "independentOn": { "enabled": true, "path": "", "volume": 65 },
    "independentSwitch": { "enabled": true, "path": "", "volume": 60 },
    "sequenceSwitch": { "enabled": false, "path": "", "volume": 60 }
  }
}
```

`sounds` 中每个事件分别保存 `enabled`、`path`、`volume`。新建配置的所有事件默认开启；切换和暂停提示默认音量低于整体启停。

`scripts/package-release.ps1` 保留原有四个启停 WAV 的存在检查，同时收录 `assets/audio/` 中全部 WAV，因此后续加入的音频会自动进入发布包。

## 界面预览

Mac／Windows 预览复用正式 `DialogSound.qml`、事件列表组件、事件定义和设置数据转换。两页入口分别展示并保存各自范围内的内存设置，取消不保存。示例数据展示默认音频可用状态，空数据可查看缺失占位；整组关闭、逐项开关、音量、文件选择示例和试听状态均可查看。预览不读取或写入 `config.json`，不访问实际音频文件、不播放声音。
