# 界面预览

预览程序独立于 Windows 按键引擎，可在 Mac 和 Windows 上使用 Qt 6.8.3 构建。
直接加载正式程序的 `AppShell.qml`、全部页面和通用控件，并使用原有图标、门派素材和主题。
不同平台使用各自的 Qt SDK 和启动脚本。

## 可以查看的内容

- 左侧导航中的按键连发、循环连发、使用统计、驱动管理、插件中心、全局设置、关于软件页面，以及默认追加到最下方的同级插件页面。所有标签均可拖动排序，靠近边缘时自动滚动；获得焦点后可用 `Alt+↑/↓` 调整位置。排序只保存在预览内存中，切换示例数据、停用后重新启用插件会保留位置。
- 插件中心保留内置、发现、已安装三个列表，默认显示已安装；提供官方／社区、类型、审核筛选，入口为“导入”和检查更新。小叽和 DD 默认均已安装，须保留至少一种可用的内置驱动，其余可停用或卸载；已卸载的驱动从已安装列表隐藏，内置标签保留安装按钮。USB 在发现中按需安装，可自由停用和卸载。官方身份紧邻名称，详情与安装位于同一操作行。示例包含来源、异常插件、待更新、待重启和启停状态；两种内置驱动均保留随包恢复入口。列表和详情隐藏滚动条，保留滚轮滚动。左侧插件页面直接加载 SDK 的状态面板，以及正式江湖桌宠与活动日历，各自使用自身图标，通过正式图标提供器着色；页面外层不显示“插件中心 / 页面名”。安装和更新只改变内存，不读插件包、不加载驱动或联网。
- 插件中心进入页面或点击右上角刷新时，复用正式页面的自动刷新入口和加载状态；预览只用内存示例模拟短暂加载，完成后清空提示，不访问实际插件目录。列表获取失败时不显示报错或地址，没有内容时发现列表留空；详情只展示用户信息，不显示能力代码和本机路径。切换列表标签、搜索或筛选不会重新发起刷新。
- 身份展示复用正式页面：列表显示经过验证的 GitHub／Gitee 发布账号，详情把“作者自述”、发布者、审核与安装来源分开；内置副本统一显示“随程序提供”，发布者和审核筛选分别包含未验证、随程序提供状态。示例包含作者自称“小叽官方”的未验证本地工具，以及完整性失败后主动重新安装的条目；安装一个社区示例后再点“导入”，可查看更换来源的确认。修复、来源变化和仓库按钮只改变内存或展示提示，不校验真实磁盘文件、联网或打开外部网页。
- 驱动页只展示当前所选示例插件的状态和管理动作，已停用或卸载的插件不提供可选驱动，未安装的 USB 不出现在详情及诊断报告中。“卸载当前驱动”操作当前插件的系统驱动，“卸载HID”清理已停用的旧 HID 驱动及其残留。插件卸载确认框复用正式页面的系统驱动清理复选框；预览只同步内存中的示例安装状态，小叽和 DD 可在保留另一种可用内置驱动时卸载，也可独立演示卸载系统驱动。
- 示例数据中包含正式「小叽 · 江湖桌宠」：通过详情或设置页开启/关闭、显示/隐藏窗口，切页后仍可运行。直接加载 `plugins/pet-xiaoji/` 的清单、设置页、后台、窗口和皮肤，复用正式 `PluginRuntime` 与窗口承载；按键页/循环页的示例运行开关及底部「暂停示例」同步到桌宠。共用 72／96／120 三档尺寸、像素练剑及生活图集、睡眠 Zzz；主界面失焦后可见的桌面窗口继续播放。窗口位置、后台选择和设置仅保存在内存，不加载原生模块或操作实际驱动。关闭示例数据或停用插件会清理后台和窗口；皮肤及动作素材完成状态见[桌宠待办](../plugins/pet-xiaoji/TODO.md)。
- 使用统计中的最近 270 天热力图和全年月度趋势；趋势支持独立切换年份及悬停查看时长，已完成月份用实线连接，本月累计段用虚线显示，未来月份留空。
- 活动日历复用 `plugins/page-calendar/` 的正式页面，预览单独注入所提供的日常和周常示例；采用月历日期网格与活动列表，支持今天前后 15 天、返回今天和手动刷新。窄窗口上下排列，隐藏滚动条、保留滚轮滚动，始终不联网。关闭示例数据后保留日历入口、显示空白内容；示例日期切换只用于看布局，不代表实际活动安排。
- 门派切换、深浅色、示例数据和空数据，以及启动/停止、控件禁用等展示状态。门派选择菜单与正式程序共用 `FactionPicker.qml`，滚动策略见[控件约定](ui-guidelines.md#按钮与控件)。
- 「其它窗口预览」中的「脆皮山庄出餐单」在任意日期展示「脆皮山庄」的已解锁小票，「脆皮山庄主题」直接展示换装后的设置页。两者复用正式页面、门派菜单、纸桶小叽和主题刷新，菜单、设置与小票的名称统一不带门派前缀；小票可立即换装或先收藏。设置页仅在启用隐藏外观时，在主题名称旁显示「查看出餐单」，当前纸桶徽记也可重看；没有独立收藏提示行，门派菜单只负责换装。切换普通门派后隐藏重看入口，收藏及当前外观在切换示例/空数据时保留，全部仅存于内存。正常徽记入口仍按电脑本地周四和 3 秒内连续点击 5 次触发，规则见[门派主题与周四彩蛋](ui-guidelines.md#门派主题与周四彩蛋)。
- 出餐单与正式程序共用直角锯齿纸张、红白斜纹、桶上标「叽」的圆头小叽、解锁星光徽记及经典红按钮；进入示例时可保留普通藏剑底色。纸面、独立锯齿边和内容共用一个容器，纸面与锯齿边的接缝处理及弹窗关闭方式均遵循[出餐单约定](ui-guidelines.md#门派主题与周四彩蛋)。页脚自然排列并锚定内层内容区底边，落款到锯齿内缘保留 12px；高度不足时仅正文滚动。换装后可查看标题栏底部的包装斜纹、浅奶油色侧栏、奶油底红字的选中导航及纸桶门派标识；条纹配色与标识尺寸遵循同一专题约定。表头与 hover 使用暖奶油色，深色下实心操作仍为经典红。
- 隐藏主题的炸鸡装饰与按下酥屑直接复用正式组件和资源：可查看快捷控制标题、设置页主题标签、状态栏与按键/循环列表空状态；炸鸡图标、桶贴纸造型及按下反馈时机统一遵循[隐藏外观约定](ui-guidelines.md#门派主题与周四彩蛋)。侧栏导航下方至少留有 136px 时出现无落款文字的红白桶，按下可查看短促摇摆、回弹与酥屑；入口增多、窗口缩小或拖动排序时隐藏。桶身与门派小叽共用正式 SVG 的透明轮廓绘制，深色下不出现裁切白块；拉高窗口可查看按压设置空位中的淡鸡腿压纹。共用按钮、导航、菜单、复选框、开关、单选、下拉选项和输入控件在按下时显示一次短促酥屑，打开弹窗的操作也即时触发，不延后示例操作，抬起不补播；滚轮滚动不触发，持续拖动不追加。切换普通门派、关闭系统动画或失活后停止。正式程序和预览共用 `CrispyControlFeedback.qml`、`CrispyEffects.qml`、`CrispyClickBurst.qml` 与 `CrispyBucketSticker.qml`，不额外保存状态或改写用户配置。
- 添加/编辑按键、按键别名、批量修改参数、配置新增/复制/重命名/删除、快捷键、提示音、悬浮窗设置、游戏进程、自检结果、诊断信息和分享、消息弹窗。
- 全局设置中的“管理进程”展示生效列表：剑网3固定为不可移除的内置项，自定义项显示图标、窗口标题和程序名；通过标准下拉选择框搜索窗口标题或程序名，列表与选择框等宽、高度最多 260 个逻辑像素，可超出管理弹窗范围，但保持在小叽主窗口内。下方空间不足时自动缩短或向上展开，点击外部、按 Esc 或失焦时收起。已添加或内置的程序不能重复添加，手动添加支持末尾 `*` 前缀匹配。正式程序读取可见窗口及窗口／EXE 图标；预览直接复用该选择框，只使用内存中的多开窗口、长标题与图标缺失示例，不枚举本机窗口。切到空数据可查看只保留内置剑网3和空候选列表的状态。
- 提示音设置使用左侧事件列表、右侧参数区，窄窗口上下排列；按键页只显示 8 项按键事件，循环页只显示 4 项循环事件和 2 项录制事件，保存时保留另一页的设置。各项可独立启用、调整音量、选择示例音频和恢复默认；示例数据展示默认音频可用状态，空数据可查看缺失占位。主界面保留整组勾选，试听只显示状态，不播放音频。文件名与触发规则见 [提示音配置](sound-cues.md)。
- 关于页中的新手引导；按键模式、循环步骤与录制说明用实际按键和秒数举例，按「怎么操作、会发生什么」说明。窗口下方的「其它窗口预览」可打开关闭确认、导入配置、更新下载、分享提示和坐标拾取界面。
- 在右侧开启「显示到浮窗」后可查看悬浮窗、拖动及锁定状态。
- 按键和循环步骤示例包含别名；编辑弹窗可修改或清空名称，列表将实际键位与名称分列显示，未命名显示「—」，长名称省略并可悬停查看全文；悬浮窗显示「名称（实际键位）」。
- 按键列表下方可查看切换模式当前段；停用当前段后，示例会回落到第一个可用切换段。
- 点击列表下方的切换键或暂停键文字可编辑，删除仍使用旁边的关闭按钮；更多暂停键菜单将编辑和删除分开。总览里的暂停键也可直接编辑。快捷键弹窗只显示键位录制和操作提示，编辑时预填原键位，不显示名称、模式、间隔或宏示例。
- 按键录制支持先按住 Ctrl／Shift／Alt 再按键盘或鼠标主键，示例包含「Ctrl+1」；只按修饰键并松开会录制单独修饰键。
- 点击位置仅对鼠标左、右键显示；中键、侧键不显示固定点位和拾取坐标，改录这些按键时会清除已有点位。「录制一轮」也只记录左、右键的位置；预览使用屏幕中央的示例坐标。
- 连发配置编辑、启用、批量修改与按压优先切换使用正式程序共用的 `RepeatModeRules`，按实际并发关系判断冲突；独立项之间、切换段之间与参与优先的按压项接管其他模式时允许互斥使用不同组合键。同修饰键、不同主键可以并发，长按修饰键可以和需要它的组合键共享。示例中的「Ctrl+1」默认停用，因为同时启用的 Shift 长按会改变它的修饰键状态。预览不执行实际修饰键保持或按键发送；完整规则见 [按键模式与冲突](key-mode-rules.md)。
- 编辑预览中的「F · 武学助手示例」可查看长按项的武学助手开关，开启或关闭后下方的模式说明与引导仍保留，并说明正式程序按住 3.1 秒再松开、Alt 暂停，以及手动按 F 后不再补按、需重新启停才接管的用法；预览仅保存到内存，不执行长按计时或收尾。
- 两页列表标题旁的「按键总览」直接显示紧凑的完整键盘布局，下方排列鼠标按键和滚轮；键帽以完整的“输出、启停、暂停、切换、修饰键”用途配合不同色块显示，多种用途显示“多用途”，停用键位显示灰色与“停用”。点击键位后在附近展开可滚动的详情面板，点击外部或按 Esc 收起；组合键同时关联主键和修饰键，重复循环步骤逐项列出。添加或编辑窗口叠加在总览上方，总览保持打开并保留选中键；保存后立即刷新，取消后仍可继续查看。总览可拖动右下角调整尺寸，窄窗口横向滚动键盘；运行中仅查看，底部「暂停示例」可查看暂停标记。所有操作仍只作用于内存示例数据。
- 循环步骤可试用插入、单步复制、拖动排序、勾选多选、表头全选、批量修改、批量复制和批量删除；行内操作依次为「更多、编辑、删除」。
- 两种列表以方框选择批量操作的行，以操作列前的“启用”开关控制启用或停用；均支持批量修改与删除，循环列表另支持批量复制。行内删除使用垃圾桶图标，批量删除使用文字按钮并显示数量确认。
- 循环列表下方可查看单轮与指定轮数的预计时长。
- 循环页「添加步骤」可切换点击、保持、按下、松开、等待和滚轮，按动作显示对应参数；批量修改可选择保持／等待时长，动作摘要和时长估算同步更新。
- 「录制一轮」可查看准备、倒计时、录制和结果确认；动作间停顿直接写入步骤间隔，同键连续按下／松开合并为保持，多键交叠保留原始顺序，确认列表同时显示动作和间隔。预览只收集本窗口输入，按 F10 或停止按钮结束，确认后追加到内存示例。正式 Windows 程序允许切回游戏录制，预览不会安装全局钩子或发送按键。
- 驱动管理页的“诊断信息”展示示例报告；正式程序的复制内容由用户主动点击触发。

所有演示状态只保存在预览进程内存中，不读写 `config.json`。
启动/停止仅切换界面状态，驱动、自启、音效、分享及更新操作使用示例数据，不执行系统操作或发起网络请求。
快捷键录制只读取预览窗口内的输入，不安装全局钩子。
编辑与确认弹窗保持应用模态；按键总览为非模态查看窗口。两者均直接使用 `DialogShell.qml` 的背景和主题边框，避免 Mac 将弹窗作为原生 sheet 绘制额外外观。

页面、弹窗、控件和图标均在正式程序的共用文件中维护，预览不保留另一套样式。
修改模型字段、页面入口或交互时，需要同步更新 `preview/` 中的示例适配，详细约定见 [界面开发规范](ui-guidelines.md)。本文中的安装、构建和启动命令供用户自行执行，全局工作约束与按需阅读入口见 [AGENTS.md](../AGENTS.md)。

## Mac

需要 Xcode 开发工具、CMake，以及 Qt 6.8.3 的 Core、Gui、QML/Quick、Quick Controls、SVG 和 Shader Tools。
本机 Qt 安装目录是 `~/Qt/6.8.3/macos`。

安装 Qt 的命令：

```bash
python3 -m venv ~/.local/share/xiao-ji-auto-key/qt-installer
~/.local/share/xiao-ji-auto-key/qt-installer/bin/python -m pip install aqtinstall
~/.local/share/xiao-ji-auto-key/qt-installer/bin/python -m aqt install-qt \
    mac desktop 6.8.3 clang_64 --outputdir ~/Qt \
    --archives qtbase qtdeclarative qtsvg --modules qtshadertools
```

在仓库目录执行：

```bash
./scripts/preview-macos.sh
```

首次执行会编译预览程序，产物为 `build-qml-preview/XiaoJiPreview.app`。
仅编译而不打开窗口：

```bash
./scripts/preview-macos.sh --build-only
```

脚本默认使用本机已安装的 `/Library/Developer/CommandLineTools/SDKs/MacOSX14.4.sdk`。
Qt 6.8.3 的 AGL 链接依赖需要使用保留该框架的 SDK。
Qt 或 SDK 位于其他位置时，分别通过 `QT_PREFIX_PATH`、`MACOS_SDK_PATH` 指定。

## Windows

使用项目已有的动态 Qt 6.8.3 和官方独立版 CMake：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\preview-windows.ps1
```

脚本默认使用 `D:\Qt\6.8.3\msvc2022_64` 和 `D:\software\cmake-3.31.6\bin\cmake.exe`。
可用 `-QtPrefixPath`、`-CMakePath` 指定实际安装位置；`-BuildOnly` 表示仅编译。
产物为 `build-qml-preview-windows\Release\XiaoJiPreview.exe`。

宿主控件与导航图标使用项目自带 SVG；插件页面图标复用 SDK 示例包内的 SVG。正式程序和预览使用同一套资源与图标提供器，插件自带 SVG / PNG 的声明和着色规则见 [插件页面](plugin-development.md#qml-页面)。
普通操作图标为 16 个逻辑像素，紧凑图标为 12；按钮点击区域保持原有尺寸。共用图标提供器按当前 DPI 请求尺寸的两倍绘制后平滑缩回，避免 100% 缩放下的小尺寸 SVG 直接栅格化丢失细节。
主界面、弹窗、浮窗和坐标提示均使用 QML 的 Qt 文本渲染；字体、字号与字重由通用控件及 `Typography.qml` 统一设置，预览入口沿用正式程序的默认文本渲染方式。
Mac 与 Windows 的正文字体和系统材质仍存在差异；正式按键、驱动与更新流程在 Windows 程序中运行。
