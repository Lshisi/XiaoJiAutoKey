# 活动日历

在小叽左侧打开“活动日历”，查看剑网3每日活动和本周安排。

- 默认查看今天，通过月历直接选择日期、切换月份或返回“今天”；可查看今天前后 15 天，共 31 个日期。
- 月历旁展示所选日期的日常：大战、战场、矿车、门派活动、驰援、秘境安排和福缘宠物；接口有内容时也显示美人图与世界首领。当周活动展示公共任务与团队秘境。没有内容的项目不占行。
- 日常按北京时间早上 7 点换日，页面保持打开时会跟随换日刷新。
- 右上角可手动刷新。获取不到内容时留空；本次打开页面时已经获取的日期继续可看，不显示网址或报错代码。
- 沿用宿主的字号、门派配色与深浅色；窄窗口下月历和活动列表上下排列，内容可换行。隐藏滚动条，保留滚轮滚动。

月历日期按钮使用左右各 4 个逻辑像素的内边距，保证紧凑的七列日期格仍能完整显示两位数；该设置只作用于日历，不改变宿主通用按钮。正式页面与预览共用 `ui/MonthNavigator.qml`。

这是纯 QML 页面插件，不需要编译 DLL，不注册驱动或后台，不读取按键配置，不控制连发，也不保存用户设置。页面打开、手动刷新或换日时批量获取日常；选择日期直接读取本次打开时的暂存内容，按需补充当周活动。

## 数据来源

使用 [JX3API 活动日历](https://www.jx3api.com/active/calendar)：

```text
GET https://www.jx3api.com/active/calendar?mode=list&num=15
GET https://www.jx3api.com/active/calendar?mode=day&num=0
```

`mode=list&num=15` 的 `detail.today.date` 为日历当天，`detail.total` 提供前后各 15 天的日常。页面按返回内容的实际日期暂存数据，切换日期直接读取对应内容，不依赖日期绑定的更新顺序，也不需要切换后再点刷新。

列表接口不包含周常；对今天至未来 15 天，按需使用 `mode=day&num=0..15` 补充 `weekly.conn` 和 `weekly.raid`，并按所在周暂存。过去日期有日常内容；所在周的周常尚未获取时留空，不向单日接口发送负数天数。

只接收 HTTP 200、`status: 200` 和有效日期。字段缺失、返回异常及联网失败均不展示技术错误。每次请求最长等待 15 秒，新请求取消同类旧请求，关闭页面取消未完成请求；返回结果按其实际日期和所在周保存，不覆盖用户当前选中的日期。本次页面内的内容退出页面后释放。

本插件不使用账号、Token 或用户个人信息。远端内容只按纯文本显示，活动安排以 JX3API 返回为准。

## 开发预览

共用预览已接入“活动日历”。正式插件页面与预览使用同一份 QML，预览只注入用户提供的示例活动，不访问接口；日期切换用于查看布局，不代表实际对应日期的日常。关闭示例数据可查看空白状态。

## 独立发布

源码目录可直接通过现有 `scripts/package-plugin.ps1` 打包，包内保留 `plugin.json`、`Main.qml`、`ui/`、日历图标及许可证。以下命令仅供明确执行：

```powershell
./scripts/package-plugin.ps1 -SourceDirectory plugins/page-calendar -PackageName XiaoJiPluginCalendar
```

已登记独立 tag、双平台发布与签名目录收录配置。官方 `xiaoji.` 插件导入仍须匹配可信插件目录，只有本地 ZIP 而尚未发布收录时不会绕过身份检查。发布后可在插件中心选择安装；主程序完整应用包不预装活动日历。

未发布阶段的本地安装包使用 `local.activity-calendar`，名称仍为“活动日历”，版本保持 `1.0.0`，不改变正式源码的官方 ID。经用户明确要求，可覆盖本地 `XiaoJiActivityCalendarLocal-v1.0.0.zip` 文件；已发布附件仍不可替换。宿主不接受直接覆盖同 ID、同版本的不同内容，安装该本地新版前先卸载旧活动日历，再导入新包。使用已修正卸载清理的主程序时，纯 QML 日历卸载后立即清理旧文件，无需重启小叽；旧版卸载残留在导入前重试清理。此次页面使用更新后的 `QuietScrollView.showScrollBar`，应先使用同步构建的主程序。

源码完成、静态核对、主程序编译、插件打包和运行验证分别记录；构建或打包不代表界面、真实日期交互及功能已经运行验证，功能由用户自行确认。
