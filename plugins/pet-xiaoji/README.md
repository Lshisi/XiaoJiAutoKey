# 小叽 · 江湖桌宠

纯 QML 独立插件，ID 为 `xiaoji.pet.xiaoji`，插件版本 `1.0.0`，最低宿主版本 `1.1.9`。默认应用包不包含桌宠；用户从插件中心或本地 ZIP 安装，并主动开启。

藏剑首版源码及宿主接口已接入，采用 Codex 风格的透明精灵图集、逐帧时长、循环起点及统一播放器，见[动画制作方向](design/animation-plan.md)。24 帧透明图集原型已完成尺寸、透明通道及落脚位置整理，逐帧细节与动作连续性仍需重制。实际显示、交互、暂停及安装行为仍需用户构建后确认；未编译、打包、启动或运行测试。素材要求见 [皮肤约定](skins/README.md)，开发状态见 [TODO](TODO.md)。

原型图集为 [skins/cangjian/atlas.png](skins/cangjian/atlas.png)，可通过[离线精灵预览](design/sprite-preview.html)选择动作并逐帧查看，也可查看[无损 WebP 动作预览](design/cangjian-preview.webp)。正式与预览共用完整颜色的透明 PNG 及播放器，当前静态 Qt 无需增加 WebP 模块。SVG 和 GIF 小样已归档。

清单显式声明必需的透明图集，缺少素材时安装/加载与打包会停止，避免发布只能显示错误的空壳插件。

## 使用与动作

- 首次开启后，后台在切页和最小化时继续运行，下次启动小叽时按宿主保存的选择恢复。关闭桌宠会停止后台并取消恢复；隐藏窗口保留后台。小叽退出时一起结束。
- 左键单击摸头，拖动移动，松开落地；右键选择桌宠设置页。设置页提供显示、隐藏、找回、大小、置顶和鼠标穿透。找回会移到主屏工作区右下方，并恢复鼠标交互。
- 默认固定藏剑皮肤。可选跟随主界面门派；尚无对应皮肤时回退藏剑，不改变主界面主题。
- 开启状态联动后，任一连发或循环运行时练剑，暂停时驻剑，全部停止后收工一次。两个引擎同时运行时，停止其中一个不会收工；部分暂停仍有活动来源时继续练剑。
- 两分钟没有桌宠互动、且没有需要联动的运行任务时打盹。开始运行立即唤醒；摸头或拖动后按最新引擎状态恢复动作。
- 仅申请 `engine.read`，不启动、停止或发送按键。动画按素材帧时长播放，不随每次按键输出发消息。
- 隐藏窗口暂停逐帧计时。桌宠窗口声明 `focusable: false`，关闭鼠标穿透仍保留不接受焦点的属性。

完整暂停联动、窗口不抢焦点和找回位置需要本次宿主改动；旧的 `1.1.9` 开发构建仅能回退到运行/停止联动，须重新构建宿主后使用完整能力。

## 结构与皮肤扩展

| 文件 | 职责 |
| --- | --- |
| `plugin.json` | 页面、后台、透明窗口、命令和资源声明 |
| `Main.qml`、`ui/Pet*Settings.qml` | 设置页及桌面选项 |
| `Background.qml`、`ui/PetController.qml` | 生命周期、闲置计时、交互动作和运行状态切换 |
| `Pet.qml` | 独立窗口内容和鼠标手势 |
| `ui/PetSession.qml` | 页面/窗口订阅状态，并在重新打开时查询快照 |
| `ui/PetSkin.qml` | 门派皮肤目录、素材路径、逐帧位置与时长、循环起点 |
| `ui/PetSprite.qml` | 通用精灵播放、眨眼与可见性处理 |
| `skins/<门派 ID>/` | 对应门派素材，藏剑为 `cangjian` |

每个门派拥有独立素材和动作描述。新增门派时，在 `PetSkin.qml` 的 `available` 增加稳定门派 ID、名称、图集和动作帧信息，再声明/收集对应资源；互动和引擎联动共用现有实现。缺少的动作应在该皮肤描述中显式映射已有动作，保留统一的 `idle`、`pet`、`drag`、`land`、`sleep`、`practice`、`rest`、`finish` 动作语义。

## 预览与独立发行

共用预览直接从资源加载本目录的清单、设置页、后台、窗口和素材，使用正式插件运行时。开启示例数据后从“江湖桌宠”页面主动开启；按键页/循环页的示例运行开关、底部“暂停示例”只修改内存状态。预览不读取用户配置，不发送输入。

用户在素材完成后可自行执行 `scripts/package-plugin.ps1 -SourceDirectory plugins/pet-xiaoji -PackageName XiaoJiPluginPet`，生成独立 ZIP；源码中的设计图、TODO 和文档不作为动作资源。正式发行入口为 `plugins/pet-xiaoji/v1.0.0` tag，对应 `XiaoJiPluginPet-v1.0.0.zip`。本次未打包、发布或修改线上目录。
