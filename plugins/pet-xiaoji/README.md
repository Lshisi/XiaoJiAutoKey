# 小叽 · 江湖桌宠

独立纯 QML 插件，默认应用包不带。当前只制作藏剑，插件 ID 为 `xiaoji.pet.xiaoji`，最低宿主版本 `1.1.9`。

当前使用首次生成的 24 帧动作原图，保留张翅、悬空、蜷身睡觉、举剑、挥剑及小跳等原有姿态。金黄羽毛、白肚皮、银杏头饰、披肩、背剑与练功剑按原图保留；整理工具只裁切及对齐位置，不缩放或重绘角色和武器。

## 使用

- 从插件中心或本地 ZIP 安装，主动开启；切页、最小化主界面时后台继续运行，关闭小叽时一起结束。
- 单击摸头，拖动摆放，松开落地；右键打开设置。设置支持显示、隐藏、找回、大小、置顶及鼠标穿透，窗口不接受键盘焦点。
- 连发或循环运行时练剑，全部暂停时驻剑，全部停止后收工。只读运行状态，不发送按键或控制引擎。
- 闲置两分钟闭目打盹，运行或互动时唤醒。摸头、落地及收工按实际帧时长播完，再恢复当前状态；连续摸头会重新播放。
- 隐藏窗口或停止后台时停止逐帧计时；减弱动画时显示静帧。

## 资源与维护

| 文件 | 用途 |
| --- | --- |
| `skins/cangjian/atlas.png` | 程序实际使用的透明 PNG 图集 |
| `ui/PetSkin.qml` | 皮肤及动作帧顺序、时长、循环位置 |
| `design/cangjian-atlas-source.png` | 首次生成的原始 24 帧图稿 |
| `design/prepare-cangjian-atlas.py` | 裁切、对齐和合图工具，需要 Pillow |
| [动作概览](design/cangjian-preview.png)、[逐帧查看](design/sprite-preview.html) | 查看当前实际图集，不连接宿主 |
| `design/factions-*.png`、`design/actions.png` | 保留的其它门派概念图和动作草图，供后续制作 |

图集为 1024×1536，4 列、6 行，每格 256×256。为保留首次原图的大小，站立脚底对齐到格内 y=244，拖起和小跳为 y=228。帧内全部元素一起平移，身体、头饰和剑均不单独缩放。

| 行，从 0 开始 | 内容 |
| --- | --- |
| 0 | 待机眨眼 |
| 1 | 摸头回应 |
| 2 | 前两格拖起，后两格落地 |
| 3 | 蜷身打盹 |
| 4 | 练剑，第 0 格也用于暂停驻剑 |
| 5 | 开心收工 |

每个动作包含 `frames` 和 `loopFrom`，单帧记录行、列及毫秒时长。`loopFrom: -1` 表示单次播放；单帧驻剑保持静止。制作脚本与离线查看读取同一份动作表。正式程序和界面预览共用本插件源码和图集。

运行包仅收集清单声明的页面、后台、窗口、图标与图集，设计资料不进入发行包。安装、后台与独立窗口约定见[插件运行时](../../docs/plugin-runtime.md)。

本插件为纯 QML，可使用 `scripts/package-plugin.ps1` 从 `plugins/pet-xiaoji` 打出独立 ZIP，无需编译插件。当前未执行打包。
