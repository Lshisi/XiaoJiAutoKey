# 小叽 · 江湖桌宠

独立纯 QML 插件，默认应用包不带。当前只制作藏剑，插件 ID 为 `xiaoji.pet.xiaoji`，最低宿主版本 `1.1.9`。

保留首版藏剑像素小黄鸡的造型、金黄羽毛、白肚皮、银杏头饰、披肩与背剑。精修只减轻粗黑外轮廓，采用更细的暖棕色过渡，保留像素颗粒与原服饰，不重设计角色。原 24 格布局继续用于待机、摸头、拖起、落地、睡觉及收工；练剑改用独立 24 帧循环，另增 24 格生活动作图集。

## 使用

- 从插件中心或本地 ZIP 安装，主动开启；切页、最小化主界面时后台继续运行，关闭小叽时一起结束。
- 单击摸头，拖动摆放，松开落地；右键打开设置。设置支持显示、隐藏、找回、大小、置顶及鼠标穿透，窗口不接受键盘焦点。
- 小／中／大分别为 72／96／120 个逻辑像素，默认中号。旧的 160／224／288 设置按原档位映射，不改写用户配置；实际屏幕尺寸仍由宿主按 DPI 处理。
- 连发或循环有效运行时循环播放起手、挥击、回剑和收势，全部暂停或被游戏门控暂停时驻剑，全部停止后收工。只读运行状态，不发送按键或控制引擎。
- 闲置约 25 秒张望、60 秒伸懒腰、95 秒打哈欠，120 秒闭目打盹，并显示飘动的 Zzz 与轻微呼吸。自动小动作不重置闲置时间；摸头或运行会唤醒。
- 摸头、落地、收工和生活短动作按实际帧时长播完，再恢复当前状态；连续摸头会重新播放。设置页和桌面窗口共用动作与结束通知。
- 桌面窗口可见时，切回游戏、主程序失焦或最小化均不冻结动画。隐藏桌宠或停止后台时停止逐帧及装饰动画；系统减弱动画时保留静帧。
- 图集以原图分辨率载入，缩小时启用平滑采样与 mipmap，减轻非整数 DPI 下的锯齿；美术仍为原像素风。

## 资源与维护

| 文件 | 用途 |
| --- | --- |
| `skins/cangjian/atlas.png` | 程序实际使用的透明 PNG 图集 |
| `skins/cangjian/practice-pixel.png` | 独立 24 帧像素练剑循环 |
| `skins/cangjian/ambient-pixel.png` | 张望与醒来各 8 格，伸懒腰与打哈欠各 4 格 |
| `ui/PetSkin.qml` | 皮肤及动作帧顺序、时长、循环位置 |
| `ui/PetSizing.qml` | 共用尺寸档位、默认值与旧档位映射 |
| `ui/PetSleepMarks.qml` | 睡眠 Zzz，按可见状态和系统动画偏好启停 |
| `design/cangjian-atlas-source.png` | 首次生成的原始 24 帧图稿 |
| `design/cangjian-atlas-refined-source.png` | 已对齐的轻描边主图集母版，供后续同步，避免重新生成粗黑边版本 |
| `design/prepare-cangjian-atlas.py` | 同步精修母版并按动作表生成多图集离线查看，需要 Pillow |
| [首版动作概览](design/cangjian-preview.png)、[逐帧查看](design/sprite-preview.html) | 首版概览供对照，逐帧页面引用当前三张实际图集，不连接宿主 |
| `design/factions-*.png`、`design/actions.png` | 保留的其它门派概念图和动作草图，供后续制作 |

主图集为 1024×1536，4 列、6 行，每格 256×256。主图格位沿用首次图集的脚底对齐（站立 y=244，拖起和小跳 y=228），不单独放大头饰或武器。

| 行，从 0 开始 | 内容 |
| --- | --- |
| 0 | 待机眨眼 |
| 1 | 摸头回应 |
| 2 | 前两格拖起，后两格落地 |
| 3 | 蜷身打盹 |
| 4 | 练剑，第 0 格也用于暂停驻剑 |
| 5 | 开心收工 |

每个动作包含 `frames` 和 `loopFrom`，可通过 `sheet` 指定独立图集，单帧记录行、列及毫秒时长。`loopFrom: -1` 表示单次播放；单帧驻剑保持静止。制作脚本与离线查看读取同一份动作表，支持在图集之间切换。正式程序和界面预览共用本插件源码和图集。

练剑图集为 6 列、4 行，24 格按行连续播放；生活图集为 4 列、6 行，第 0–1 行张望、第 2 行伸懒腰、第 3 行打哈欠、第 4–5 行醒来。新增图集的生成提示与风格约束见 [素材提示](design/asset-prompts.md)。

运行包仅收集清单声明的页面、后台、窗口、图标与图集，设计资料不进入发行包。安装、后台与独立窗口约定见[插件运行时](../../docs/plugin-runtime.md)。

本插件为纯 QML，可使用 `scripts/package-plugin.ps1` 从 `plugins/pet-xiaoji` 打出独立 ZIP，无需编译插件。本地开发副本使用独立的非官方 ID 时，右键设置入口根据 `pluginApi.pluginId` 导航，无需再修改 QML 路由。

当前按用户要求保持插件版本 `1.0.0`。本地开发包使用 `local.pet-xiaoji`，重新打包时在文件名中附加时间，保留旧 ZIP；已安装相同 ID、相同版本的旧包时，先从插件中心卸载，再导入新的本地包。正式发行的版本与附件不可覆盖规则仍见[插件发布](../../docs/plugin-release.md)。
