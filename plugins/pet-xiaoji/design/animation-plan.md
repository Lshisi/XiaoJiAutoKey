# 藏剑桌宠 · 动画制作方向

## Codex 桌宠参考

静态查看了本机 `com.openai.codex` 客户端 `26.1120.41243` 的安装包，未启动或修改客户端。

- 内置九种造型分别引用透明 WebP 精灵图集，共用同一个播放器；不是直接播放 GIF。
- 当前内置图集为 1536×2288，8 列、11 行，每格 192×208。前九行动作，后两行提供 16 个朝向；这是该客户端版本的实现，不是本插件需要采用的尺寸。
- 动作包括待机、招手、跳跃、左右跑动、工作、等待、审阅和失败，每组使用 4–8 个关键帧。
- 播放器按每帧独立时长切换图集位置，支持循环、短动作结束后返回待机，以及减弱动画时显示静帧。
- 安装包只能说明存储和播放方式，不能据此确定官方原画最初由手绘、生成模型或三维工具制作。

观察位置为安装包内的 `webview/assets/async/49792.ab5b643c25.js`（精灵布局与播放器）、`254985.0f45df16bb.js`（造型资源表）及 `codex-spritesheet-v6.922b99db4b.webp`。仅参考组织方式，不把客户端代码或图片作为插件素材。

官方功能说明见 [Pets](https://learn.chatgpt.com/docs/pets)。

## 已选择的实现

沿用选定的精致像素小叽，采用 Codex 的透明精灵图集、逐帧动作表及统一播放器方案。SVG/程序简笔造型和 GIF 制作路线已停止，旧小样保存在 [archive](archive/)，仅作历史参考。

- `ui/PetSkin.qml` 的每个动作包含 `frames` 和 `loopFrom`。单帧记录行、列和毫秒时长；`loopFrom` 为循环起点，`-1` 表示播完停在最后一帧。
- `ui/PetSprite.qml` 只加载一次完整图集，通过移动图集位置显示当前格，保持完整 RGBA 颜色，不做 GIF 色板量化或两帧混色。隐藏、后台停止及减弱动画时停止计时，动作切换从第一帧重新计时。
- 待机采用长停留与短眨眼，练剑分别设置蓄势、举剑、挥动与回势的时长；摸头、落地和收工的结束仍由现有控制器处理。
- 正式与预览共用同一份图集、动作描述和播放器，不复制客户端的代码或美术资源。

当前项目静态 Qt 只构建 `qtbase`、`qtshadertools`、`qtdeclarative`、`qtsvg`，没有加入 WebP 解码模块。因此运行素材使用完整颜色、真实透明的 PNG 图集；它采用同样的精灵播放方式，不为文件扩展名增加宿主依赖。WebP 无损图集保存在设计目录用于颜色与组织方式参考。

## 素材状态

现有 `skins/cangjian/atlas.png` 仍为生图原型。播放器和无损预览已经改为上述方式，但帧间的脸型、银杏、披肩、背剑细节及动作连贯性还需重制。后续制作应围绕同一只选定的小叽逐帧修整，保留一致轮廓、配色及装饰；不能只改文件格式就标记为美术完成。

没有编译或启动应用，运行效果由用户构建后确认。
