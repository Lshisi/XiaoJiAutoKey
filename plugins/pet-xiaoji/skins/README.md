# 桌宠皮肤素材

运行素材与动作逻辑分开维护。每个门派一个稳定 ID 和独立目录，藏剑为 `cangjian`。正式与预览使用同一份资源及 `ui/PetSprite.qml`，不为预览重新绘制桌宠。

## 藏剑图集约定

目标文件为 `cangjian/atlas.png`，真实透明 RGBA，1024×1536，共 4 列、6 行，每格 256×256。各帧保持相同比例，身体水平中心为格内 x=128，落脚基线 y=224；小剑、爱心、银杏等装饰不得超出单格。拖起、跳跃可在格内抬起脚底，不能改变角色比例。

| 行（从 0 开始） | 列 | 动作 |
| --- | --- | --- |
| 0 | 0–3 | 待机睁眼、半闭眼、闭眼、睁眼 |
| 1 | 0–3 | 摸头回应，微笑、眯眼、蹭头、恢复 |
| 2 | 0–1 | 拎起悬空的两个姿势 |
| 2 | 2–3 | 落地轻压、站稳 |
| 3 | 0–3 | 蜷身打盹与呼吸 |
| 4 | 0–3 | 持剑准备、举剑、挥剑、回势；第 0 格兼作暂停驻剑 |
| 5 | 0–3 | 收剑、张翅、小跳、落地微笑 |

造型以 `design/factions-01.png` 左上角及 `design/actions.png` 的藏剑小叽为参考：金黄羽毛、白肚皮、黑豆眼、弯呆毛、橄榄金小披肩、银杏挂饰和背后小剑。像素边缘清晰；无文字、标题、网格或背景色，不以棋盘纹代替透明度。

本次仅提交源码和素材约定，不包含正式动作图。图集由用户后续制作，放入 `skins/cangjian/atlas.png`；已有 `design/` 图片仅为概念参考。清单显式声明 `atlas.png`，到位前宿主和打包脚本会拒绝缺少资源的插件，共用预览显示清单资源错误，不能标记为功能完成。

新增门派可以使用不同帧数和时长，具体由 `ui/PetSkin.qml` 的描述决定。运行时只收集需要的皮肤文件；制作参考与生成提示不进入发布资源。
