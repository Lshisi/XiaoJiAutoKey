# 桌宠皮肤素材

运行素材与动作逻辑分开维护。每个门派一个稳定 ID 和独立目录，藏剑为 `cangjian`。正式与预览使用同一份资源及 `ui/PetSprite.qml`，不为预览重新绘制桌宠。

## 藏剑图集约定

文件为 [cangjian/atlas.png](cangjian/atlas.png)，真实透明 RGBA，1024×1536，共 4 列、6 行，每格 256×256。各帧保持相同比例，身体水平中心为格内 x=128，落脚基线 y=224；小剑、爱心、银杏等装饰不得超出单格。拖起、跳跃可在格内抬起脚底，不能改变角色比例；当前这三帧的脚底为 y=208。

| 行（从 0 开始） | 列 | 动作 |
| --- | --- | --- |
| 0 | 0–3 | 待机睁眼、半闭眼、闭眼、睁眼 |
| 1 | 0–3 | 摸头回应，微笑、眯眼、蹭头、恢复 |
| 2 | 0–1 | 拎起悬空的两个姿势 |
| 2 | 2–3 | 落地轻压、站稳 |
| 3 | 0–3 | 蜷身打盹与呼吸 |
| 4 | 0–3 | 持剑准备、举剑、挥剑、回势；第 0 格兼作暂停驻剑 |
| 5 | 0–3 | 收剑、张翅、小跳、落地微笑 |

造型以 `design/factions-01.png` 左上角及 `design/actions.png` 的藏剑小叽为参考：金黄羽毛、白肚皮、黑豆眼、弯呆毛、橄榄金小披肩、银杏挂饰和背后小剑。像素边缘清晰；无文字、标题、网格或背景色，不以棋盘纹代替透明度。

当前图集为生图原型，已静态核对尺寸、透明通道、24 个帧格、动作顺序及落脚位置；逐帧细节、颜色与动作连续性尚需按[动画制作方向](../design/animation-plan.md)重制，不能视为最终美术资源。没有编译、打包或启动应用验证。清单仍显式声明 `atlas.png`，沿用已有资源缺失检查；资源到位不代表安装、显示与交互已经运行确认。

## 动作描述

`ui/PetSkin.qml` 的 `actions` 使用 JSON 字面量，供 QML 播放器及设计预览共用。每个动作有 `frames` 和 `loopFrom`，每帧包含 `row`、`column`、`duration`；帧时长单位为毫秒。`loopFrom` 是从 0 开始的循环起点，`-1` 为单次播放并停留末帧。单帧动作直接显示静帧。

新增门派可以使用不同帧数和时长；动作切换从首帧重新计时，暂停和隐藏停止计时。运行时只收集需要的 PNG 皮肤文件；制作参考、WebP 对照、离线预览及生成提示不进入发布资源。当前静态 Qt 未构建 WebP 解码模块，正式 PNG 与 Codex 的 WebP 使用相同的透明精灵图集组织方式。
